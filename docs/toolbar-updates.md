# 工具栏更新 1.114.14

## 更新内容
- 统一侧栏、顶部工具栏和 AI 窗口的逐帧调度、拖动遮罩及公共样式。
- 未安装、启用或停用 AI 时，主程序均独立提供侧栏与工具栏拖动支持。
- 保留 Esc 取消、浮动位置记忆；拖动中停用 AI 会正确清理遮罩。
- 新工具栏兼容旧 AI；AI 1.3.7 在旧工具栏上按需加载兼容实现，最低版本仍为 1.114.3。

打开“更多 → 插件市场 → 工具栏更新”自动检查；下载校验后选择“退出并完成安装”或“取消”。安装器等待所有 Typora 窗口退出，成功后自动重新打开 Typora。AI 阅读助手通过“浏览市场”独立更新到 1.3.7。
