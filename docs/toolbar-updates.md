# 工具栏更新 1.114.13

## 更新内容
- 修复未安装 AI 阅读助手时左侧栏拉伸延迟，侧栏与正文边界同步移动。
- 恢复顶部工具栏拖动、浮动、固定切换，浮动位置在重启后保留。
- 移除顶部重复的插件市场按钮，统一从“更多 → 插件市场”进入。
- 首次安装的关系图谱默认浅色；已有配色选择保留。

拖动左侧六点手柄或工具栏空白处可浮动，旁边按钮可固定回顶部。重新安装 Typora 后可再次运行 install.cmd 恢复工具栏。

打开“更多 → 插件市场 → 工具栏更新”会自动检查更新。有新版时点击“更新”，下载校验后选择“退出并完成安装”或“取消”。安装器等待所有 Typora 窗口退出，安装成功后自动重新打开 Typora。旧版首次升级沿用其原有更新流程。

主程序不自动安装或更新 AI 模块，AI 阅读助手继续使用独立的 1.3.6 版本。
