# 工具栏更新 1.114.16

## 更新内容
- 修复从知识库打开文献时，文献与知识库之间短暂闪回的问题；打开失败或取消时恢复知识库。
- 修复 Google Drive 备份将 LaTeX 公式误判为本地绝对路径的问题，保留真实绝对路径检查及图片、引用和附件备份。
- 保留工具条直接拖动与顶部吸附；AI 阅读助手继续独立使用 1.3.7。
- Google Drive 备份使用独立授权，无需额外安装 Codex Google Drive 插件。

工具条空白处可直接拖动，到顶部附近松开即可吸附；按钮点击、Esc 取消与位置记忆保持可用。

打开“更多 → 插件市场 → 工具栏更新”自动检查；下载校验后选择“退出并完成安装”或“取消”。安装器等待所有 Typora 窗口退出，成功后自动重新打开 Typora。AI 模块独立管理，无需随此版重新安装。
