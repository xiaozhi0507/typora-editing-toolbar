# 工具栏更新 1.114.12

## 更新内容
- 本版用于验证本地更新流程：自动检测、下载校验、退出安装及完成后自动打开 Typora。
- 包含 1.114.11 的安装启动修复：安装任务就绪后才请求退出，避免出现“安装任务未能启动”。
- 更新状态统一显示在页面顶部，移除卡片内重复通知。
- AI 阅读助手 1.3.6 独立更新，欢迎名句扩充至 100 条。

打开插件市场或切换到工具栏更新页会自动检查；网络恢复后可重新进入页面。下载并校验完成后，原生对话框提供“退出并完成安装”和“取消”。确认安装后，先确认后台任务已就绪，再交由 Typora 原生退出流程处理未保存文档。安装器等待所有窗口退出，成功后自动打开 Typora。

若在保存提示中取消退出，可重新打开插件市场，选择“工具栏更新 → 取消等待”。失败不强制退出、不自动打开，保留失败状态以便重试。AI 模块独立管理。

旧版首次升级使用其现有安装逻辑；需要安装新版后才能完整验证新版退出安装与重开流程。本次不覆盖本机，由用户自行测试。
