# 工具栏更新 1.114.15

## 更新内容
- 移除工具栏旁的独立拖柄和固定按钮，直接按住工具条空白处即可拖动。
- 拖到顶部附近显示吸附提示，松开后固定；移出吸附区域后松开保持浮动。
- 保留按钮点击、Esc 取消和位置记忆，浮动与固定状态均可在重启后恢复。
- 未安装、启用或停用 AI 阅读助手时均可使用；AI 模块保持 1.3.7。

工具条获得键盘焦点后可用方向键移动，Home 固定到顶部。

打开“更多 → 插件市场 → 工具栏更新”自动检查；下载校验后选择“退出并完成安装”或“取消”。安装器等待所有 Typora 窗口退出，成功后自动重新打开 Typora。AI 模块独立管理，无需随此版重新安装。
