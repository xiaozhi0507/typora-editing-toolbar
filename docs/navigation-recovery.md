# 升级与重装恢复

工具栏 1.114.29 与 AI 阅读助手 1.3.13 分别更新。主程序升级不自动更新独立的 AI 模块；另一台电脑应同时检查这两个版本，更新后完全退出并重开 Typora。

欢迎页停下操作 12 秒后随机换句。正文、助手和未发送的输入框获得焦点均不阻止；第一次发送消息后停止。系统开启减少动态效果时直接换文字。动画 API 不可用或完成事件停滞时会恢复可读文字并继续轮换。选择诗句、打开助手菜单或模态对话框时暂停。无需显示倒计时。

## 收藏与置顶

普通升级只更新程序，不清除用户数据。首次运行新版会把现有页面收藏、置顶和分区从浏览器缓存备份到 Typora 用户数据目录的 editing-toolbar/document-navigation.json，并保留上一份有效记录。缓存丢失时读取校验通过的本机备份；主动取消收藏或置顶会正常保存，不会在重开页面时复活。

选用知识库后，这些导航记录也写入该库 library.json 的 documentNavigation 字段。新用户配置重新选取同一完整文件夹即可恢复记录，库内路径改用相对路径，整个文件夹移动后仍能定位。外部文件的收藏只保留路径，不会额外复制文件；换电脑后外部原路径可能不存在。项目文件夹的信任授权仍须在新电脑明确确认。

## 条目恢复

保留整个知识库文件夹，尤其是 library.json、library.json.previous 和 storage 子文件夹。重新安装 Typora、安装工具栏，然后选择这个文件夹，会载入原条目、分类、阅读状态、星标及附件。书籍原目录的外部链接也须保留；单独保留 Markdown 文件不能恢复原条目的全部元数据。

索引损坏时优先从有效的 library.json.previous 恢复并提示。两个索引均丢失但附件仍存在时，新版会明确报错，不会把已有资料覆盖为空库。恢复上一版备份可能少于最后一次保存的更改。

升级前可先备份整个知识库。新版保存机制必须至少运行一次并选用知识库，才能备份旧版中仅存在本机缓存里的收藏和置顶；已经删除且无备份的数据无法凭空还原。
