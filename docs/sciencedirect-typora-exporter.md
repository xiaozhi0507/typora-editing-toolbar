# ScienceDirect → Typora

版本：0.5.12

将浏览器当前可访问的 ScienceDirect 全文保存为 Markdown、图片、附件与引用索引。无需 API Key，不执行翻译。

## 安装

1. 完整解压 ZIP。
2. Chrome 打开 `chrome://extensions`，启用开发者模式，选择“加载已解压的扩展程序”，选中 `extension` 文件夹。
3. 安装配套 Typora 工具栏 v1.113.3 或更新版本，打开 Typora 后，在扩展设置中授权连接。
4. 刷新 ScienceDirect 论文页，点击扩展按钮保存。

## 0.5.12 更新

知识库连接迁移到本机端口 23120，避开 Zotero 的端口；先核验 Typora 服务，再请求导入。错误提示区分未启动、非 Typora 服务和授权失效。两端均需更新；旧版扩展请在 Chrome 重新加载并刷新论文页。

保留本地 ZIP 导出、图片与补充材料、公式和引用索引。内容访问范围由当前网页授权决定。个人导出文献和连接凭据不包含在本发布包中。
