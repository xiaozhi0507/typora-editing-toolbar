# AI 阅读助手

当前模块 **1.2.0**，最低工具栏 **1.110.0**，推荐使用 [工具栏 v1.113.1](https://github.com/xiaozhi0507/typora-editing-toolbar/releases/tag/toolbar-v1.113.1)。完整安装包已包含此模块；无需重复安装。

## 安装与更新

打开工具栏“插件市场”，默认使用官方地址并自动检查更新。“浏览市场”按本地版本显示“安装”“更新”或“无需更新”，名称旁显示版本号。选定更新后预览、确认信任并安装，按提示重新启用模块或重启 Typora。

手动安装：下载 [ai-reading-assistant-1.2.0.zip](https://github.com/xiaozhi0507/typora-editing-toolbar/releases/download/ai-reading-assistant-v1.2.0/ai-reading-assistant-1.2.0.zip)，在市场的“本地安装”导入 ZIP，预览后确认。请使用 Release 附件，不要下载 GitHub 自动生成的 Source code。旧版宿主请先更新完整工具栏。

## 功能

阅读问答、AI 编辑、网页助手、对话历史、提示词、技能和 AI 插件连接，以及项目、终端、代码编辑器和 Notebook。模块开关统一控制这些功能；禁用和卸载保留用户配置与数据。模型或服务账户需在本机自行配置，分发包不含凭据。

标签页的 Markdown 文档可拖入助手作为资料；技能与插件列表刷新带旋转及淡入反馈。科研绘图 Skill 从“技能”页面导入，Chrome 导出扩展在浏览器安装。
