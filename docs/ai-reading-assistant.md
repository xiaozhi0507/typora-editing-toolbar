# AI 阅读助手

当前模块版本：1.1.0。最低工具栏版本：1.108.0。

## 包含功能

- 文档阅读问答、AI 编辑、网页助手、对话历史、提示词。
- 模型配置、技能及 AI 插件连接。
- 项目侧栏、终端、Python / HTML / JavaScript 等代码编辑器、Notebook。

## 安装与启停

工具栏安装包随附此模块。可在工具栏“插件市场”中使用开关启停，也可添加[官方模块市场](../README.md#添加官方模块市场)后下载独立模块。

停用时会停止助手生成和终端 / Notebook 进程、关闭相关面板并保存会话与编辑草稿。项目文件、模型配置、历史及原有数据保留。重新启用后恢复相关功能；历史会话可以从对话历史打开。已运行代码产生的文件不会因停用而撤销。

Markdown 标签、收藏、双栏阅读、笔记、知识库及云备份不随 AI 模块关闭。

## 模型和连接

在 AI 阅读助手设置中配置自己的模型服务或网页连接。发布包不包含任何人的 API 密钥、登录凭据、个人技能或第三方插件账户；这些内容由使用者在本机配置。模型服务的可用性和费用以所选服务为准。

## 更新

在插件市场点击“检查更新”。独立模块更新无需重装工具栏；若新版本提高最低工具栏要求，请先更新工具栏。安装包通过 SHA-256 校验，更新后需要重新启用并确认信任。

## 文档入口

模块卡片的问号可指向本页。没有配置时，点击问号并填入：

```text
https://github.com/xiaozhi0507/typora-editing-toolbar/blob/main/docs/ai-reading-assistant.md
```

配置后点击打开文档，悬停查看网址，右键问号可修改。本页可以直接在 GitHub 编辑，用于持续补充使用说明。
