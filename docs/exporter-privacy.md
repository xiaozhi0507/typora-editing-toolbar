# ScienceDirect → Typora 隐私说明

更新日期：2026-10-11

本扩展由 GitHub 用户 xiaozhi0507 维护，用于将用户有权访问的 ScienceDirect 论文导出到本机。与 Elsevier、ScienceDirect 和 Typora 官方无隶属关系。

## 处理哪些数据

- 用户点击保存时，读取当前论文页面的标题、作者、摘要、正文、参考文献、图片地址及附件地址，用于生成 Markdown 和配套资源。
- 获取论文图片、补充材料时，请求 ScienceDirect / Elsevier 资源服务器；资源请求不携带浏览器 Cookie。本扩展不读取、导出或保存账户密码，不绕过网站权限。
- 设置、分类选择和 Typora 配对信息保存在浏览器扩展的本地存储中。配对后的导出仅发送到本机 127.0.0.1 服务，再由 Typora 工具栏写入用户指定目录。
- GitHub 解压版检查更新时向本项目的 GitHub 公开地址请求版本信息，不携带论文内容、配对令牌或 API Key。商店版由浏览器负责更新，不访问 GitHub 更新目录。

## 使用、保存与删除

数据仅用于用户请求的论文导出、知识库保存和扩展设置。扩展没有广告、统计追踪或开发者运营的数据收集服务器，不出售或共享论文、个人数据用于广告或征信等用途。

卸载扩展会删除扩展的本地设置。已经保存的 ZIP、Markdown、图片以及 Typora 知识库文件由用户管理，卸载扩展不会删除它们；可直接在对应文件夹中删除。

浏览器商店和资源网站可能按照各自的隐私政策处理网络请求。用户需要遵守论文网站的使用条款及内容权利限制。

## 联系

隐私问题请通过 [项目 Issues](https://github.com/xiaozhi0507/typora-editing-toolbar/issues) 联系维护者。请勿公开上传配对令牌、账号信息或不适合公开的文献内容。
