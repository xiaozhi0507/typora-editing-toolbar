## 使用

在 AI 阅读助手的“设置 → 技能 → 添加”中导入 ZIP，再启用该技能。也可完整解压 `scientific-python-plotting` 文件夹到支持 SKILL.md 的工具所指定的技能目录。它不是工具栏功能模块，也不是 Chrome 扩展。

适用于 Matplotlib / Seaborn 科研图、组合面板、统计图与论文排版：集中参数、中文分区注释、显式颜色、字体回退，输出 PDF + PNG；需要时可另存 SVG。真实数据、统计方法和期刊要求由具体任务确定。参考文件里的本机示例路径只用于已有工作习惯，路径不存在时仍可使用通用规范与模板。
